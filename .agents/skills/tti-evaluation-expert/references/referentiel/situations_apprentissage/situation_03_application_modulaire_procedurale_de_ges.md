# Exemple de Situation d'Apprentissage 3 : Application modulaire procédurale de gestion (5e)

# EXEMPLE DE SITUATION D'APPRENTISSAGE

#### **Attitudes :**

o Définir les acronymes spécifiques à l'informatique o Utiliser les termes anglais techniques courants o Communiquer en utilisant le vocabulaire spécifique et le langage adéquat

## Consignes

Pour répondre à la demande d'un client, un collègue de travail a réalisé un script pour la mise en place d'une application.

Il te fournit son script et te demande de vérifier s'il rencontre la charte de programmation\* acceptée par le groupe de travail.

## Documents fournis aux élèves

Une contextualisation de la demande initiale et un script comprenant la charte de programmation\* définie en classe concernant la mise en place :

- des conditionnelles,
- des itératives,
- des fonctions

#### Commentaires

Lorsque les élèves ont lu les documents, le professeur dirige un échange entre les élèves pour faire émerger une stratégie possible pour répondre à cette demande. Il amènera ceux-ci à établir la planification suivante :

− La réalisation d'un tableau des variables présentes ainsi que leurs contenus. − L'exécution pas à pas du script dans l'inspecteur de code en parallèle d'une vérification du tableau. La situation d'apprentissage doit être construite dans le but d'amener les élèves à s'interroger sur la façon de déclarer les variables d'un programme, à apprendre à déboguer un script des erreurs de logique et à vérifier les résultats d'un script. La situation d'apprentissage permet également de préciser l'organisation du langage en insistant sur l'objet Windows.
